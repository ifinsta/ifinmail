# .agents

Skills that keep agent-made UI aligned with the approved ifinmail redesign.

| Skill | Use it when |
| --- | --- |
| `skills/ifinmail-design-system` | Before designing, redesigning or reviewing any UI. Rules, tokens, patterns, template-to-board map |
| `skills/ifinmail-template-builder` | Creating or changing a Django template, partial, stylesheet or page script |
| `skills/ifinmail-design-audit` | Finishing or reviewing a UI change. `scripts/audit.sh` plus a manual checklist |

Reference design: https://claude.ai/artifact/D9asdXKM7QCbXmDFgkjCCE (all 50 templates). Inspiration: https://claude.ai/artifact/SLYdVZjTPp1W1S69kfsrbf.

Each skill is a folder with a `SKILL.md` (front matter `name` and `description`) and optional `references/` and `scripts/`.
