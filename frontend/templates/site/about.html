{% trans 'About' %}

{% trans 'Mail you own, without the usual weekend of work.' %}

{% trans 'Running your own mail server is possible, but fragile: DNS, certificates, authentication, reputation and backups each fail quietly. This project puts them in one place and checks them continuously.' %}

{% trans 'What it is' %}

{% trans 'A Django console and a set of well-known open-source services, run as containers on a single server: Postfix for SMTP, Dovecot for IMAP, Rspamd for filtering, Knot for DNS, PostgreSQL and Redis. The console configures them, watches them and explains what it sees.' %}

{% trans 'We chose established software over inventing our own, and we keep the number of moving parts low so one person can understand and operate the whole system.' %}

{% trans 'How we work' %}

  • {% trans 'Plain language.' %} {% trans 'Every check says what is wrong and what to do next.' %}
  • {% trans 'Few dependencies.' %} {% trans 'We avoid adding packages when a small amount of code will do.' %}
  • {% trans 'Reversible changes.' %} {% trans 'Updates snapshot first. Plugins can be removed and their effects go with them.' %}
  • {% trans 'Honest limits.' %} {% trans 'We document what is not included, such as webmail and certifications.' %}

{% trans 'What it is not' %}

{% trans 'It is not a hosted service and not a bulk-mailing tool. It is built for the mail of people and organisations who want to run their own server, and it works best when someone owns the job of looking after it.' %}
