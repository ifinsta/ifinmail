{% trans 'Features' %}

{% trans 'Everything a mail server needs, and nothing it does not.' %}

{% trans 'Each part below ships in the box and is managed from one console. Where something is not included, we say so.' %}

{% trans 'Mail' %}

{% trans 'Standard protocols, so people keep the mail app they already use.' %}

  • {% trans 'Send and receive with any client.' %} {% trans 'IMAP on 993 and submission on 587 or 465. Mail apps configure themselves from the domain.' %}
  • {% trans 'Many domains, many mailboxes.' %} {% trans 'Quotas per mailbox, aliases and forwarding, and a switch for self-registration that is off by default.' %}
  • {% trans 'Calendars and contacts.' %} {% trans 'CalDAV and CardDAV are served with the mailbox address and password, with an optional shared directory so a colleague’s photo appears in your contacts and mail apps. Switch them off if you do not need them.' %}
  • {% trans 'No webmail.' %} {% trans 'People read mail in an email app. The console is for administrators, and people with a plain mailbox see their app settings there.' %}

{% trans 'Deliverability' %}

{% trans 'Mail that arrives, and a clear reason when it does not.' %}

  • {% trans 'Authenticated by default.' %} {% trans 'Every domain gets its own DKIM key, and SPF, DMARC and MTA-STS records are published for it.' %}
  • {% trans 'Checks for the usual causes.' %} {% trans 'Port 25, reverse DNS, DNS records and blocklist listings are tested and explained in System health.' %}
  • {% trans 'Spam filtering with Rspamd.' %} {% trans 'Incoming mail is scored and filtered, and the settings you may change are exposed as plain options.' %}

{% trans 'DNS and certificates' %}

{% trans 'The two things most often wrong on a home-made mail server.' %}

  • {% trans 'This server answers DNS.' %} {% trans 'Records for every domain are generated and kept current, signed with DNSSEC. Prefer another DNS host? Connect Cloudflare, Porkbun or DigitalOcean, or export the records.' %}
  • {% trans 'Certificates from Let’s Encrypt.' %} {% trans 'Issued and renewed for the mail host and the client-configuration names, or upload your own.' %}
  • {% trans 'Entry points you control.' %} {% trans 'See every open port with a live check, close the ones you do not use, block networks and cap new connections per address.' %}

{% trans 'Protection' %}

{% trans 'Optional policies that follow what large providers do.' %}

  • {% trans 'Inbound protection.' %} {% trans 'Refuse or quarantine dangerous attachments, follow senders’ DMARC policies, trust named forwarders, and keep block and allow lists.' %}
  • {% trans 'Outbound policy.' %} {% trans 'Per-mailbox sending limits, and an automatic pause with an alert when a mailbox behaves like a stolen password.' %}
  • {% trans 'Mailbox care and a compliance journal.' %} {% trans 'Tidy Trash and Junk, warn people before a quota fills, and keep a copy of all mail in an archive mailbox.' %}

{% trans 'Operations' %}

{% trans 'Looking after the server without living in a terminal.' %}

  • {% trans 'System health.' %} {% trans 'One verdict, grouped checks, and the fix for each one.' %}
  • {% trans 'Logs and audit trail.' %} {% trans 'Searchable activity and errors. Each audit entry is chained to the one before it, so tampering shows.' %}
  • {% trans 'Backups, updates and rollback.' %} {% trans 'Encrypted nightly backups with an optional off-site copy; updates snapshot first and undo themselves if the new version is unhealthy.' %}
  • {% trans 'Two-factor sign-in and roles.' %} {% trans 'Authenticator-app codes for administrators and permission-based roles.' %}

{% trans 'Plugins and assistant' %}

{% trans 'Extend it without touching the mail software.' %}

  • {% trans 'Marketplace.' %} {% trans 'A plugin is a declarative file of settings. It cannot run code, and everything it sets is validated twice.' %}
  • {% trans 'Assistant.' %} {% trans 'Ask why mail is bouncing and get an answer built from your own checks. It stays off until you connect any OpenAI-compatible model, it can only read or draft changes, and applying is always your click.' %}
