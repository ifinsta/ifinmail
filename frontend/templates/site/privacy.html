{% trans 'Who is responsible' %}

{% trans 'This server is run by its operator, who decides what is kept and why. The project that publishes the software does not receive your mail or your account details. The one exception is a release check, described below.' %}

{% trans 'What is stored' %}

  • {% trans 'Account details: your address, a hash of your password (never the password), your quota and, for administrators, roles and two-factor settings.' %}
  • {% trans 'Your mail, in your mailbox, until you or the operator delete it.' %}
  • {% trans 'An audit trail of administrative actions: who did what, and when. It is kept for 365 days unless the operator sets another period.' %}
  • {% trans 'Operational logs and error records needed to run and secure the server.' %}
  • {% trans 'Encrypted backups of all of the above, kept as long as the operator’s backup schedule keeps them.' %}

{% trans 'Cookies and browser storage' %}

{% trans 'The console sets a session cookie to keep you signed in and a security cookie that protects forms. Your theme and layout choices are kept in your browser. There are no analytics, no advertising and no tracking scripts. These public pages load their typefaces from this server; console pages may load them from Google Fonts, depending on how the operator configured the server.' %}

{% trans 'What leaves this server' %}

  • {% trans 'Mail you send travels to the recipient’s mail server, as email always does.' %}
  • {% trans 'About every six hours the server asks GitHub whether a new release exists, which tells GitHub the server’s address. The operator can switch this off.' %}
  • {% trans 'If the operator connects the assistant, an administrator’s question and the results of server checks are sent to the model service they chose. Message contents, passwords and keys are not sent, and conversations are kept for 30 days.' %}
  • {% trans 'Certificates are requested from Let’s Encrypt, and DNS changes may be sent to a DNS provider the operator connected.' %}

{% trans 'Your choices' %}

{% trans 'You can ask the operator what is held about you, to correct it, to export your mail, or to delete your account. Closing an account removes its login; mail that was already backed up leaves the backups when they expire.' %}
