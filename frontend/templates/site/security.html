{% trans 'Security' %}

{% trans 'Specific protections, and honest limits.' %}

{% trans 'This page lists what is built in and can be checked, not adjectives. You run the server, so some of the work is yours.' %}

{% trans 'In transit' %}

  • {% trans 'Signing in to send mail is refused unless the connection is encrypted.' %}
  • {% trans 'TLS 1.2 or newer for sending, receiving and mailbox access.' %}
  • {% trans 'Outgoing mail is signed with a DKIM key per domain, and SPF, DMARC and MTA-STS records are published.' %}
  • {% trans 'The console is served over HTTPS with a Content Security Policy.' %}

{% trans 'Access' %}

  • {% trans 'Two-factor authentication with authenticator-app codes, and one-time recovery codes.' %}
  • {% trans 'Roles with named permissions. The first administrator must change the printed password at first sign-in.' %}
  • {% trans 'Senders may only use addresses that belong to their own login.' %}
  • {% trans 'Stored secrets, such as a model API key, are encrypted and never shown again.' %}

{% trans 'Detection and records' %}

  • {% trans 'Every administrative change is written to an audit trail, kept 365 days by default.' %}
  • {% trans 'Each entry carries a hash of the one before it, and a command verifies the chain.' %}
  • {% trans 'A mailbox that suddenly sends far more than usual is paused and the administrators are told.' %}

{% trans 'Your data and backups' %}

  • {% trans 'Your mail lives on your server. Nothing is sent to us.' %}
  • {% trans 'Backups are encrypted. An off-site copy goes over SSH and is checked by hash.' %}
  • {% trans 'The assistant sends only your question and check results to the model host you chose, never message contents, passwords or keys.' %}

{% trans 'The software' %}

  • {% trans 'The source is public, so you can read what runs on your server.' %}
  • {% trans 'Python dependencies are pinned by hash and audited for known vulnerabilities every week.' %}
  • {% trans 'Plugins are declarative settings. They cannot run code.' %}

{% trans 'What we do not claim' %}

{% trans 'There is no SOC 2, ISO 27001 or similar certification, and no independent security audit has been published. We do not offer a service-level agreement. Because you operate the server, its operating system, firewall, passwords and physical security are your responsibility. Only the latest release receives security fixes.' %}

{% trans 'Reporting a vulnerability' %}

{% trans 'Please report privately, not in a public issue. We acknowledge a report within three working days and assess it within seven. Critical issues are fixed within seven days and high-severity issues within thirty.' %}
